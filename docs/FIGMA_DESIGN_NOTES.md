# Дизайн из Figma (with Danya) — анализ превью

Источник: figma.com/design/wQub0nBCBf2i53s5VU31AL (node 22-54), канва 9322x4725,
фон канвы #1E1E1E, превью 800x405 (весь canvas render).

## Палитра (извлечена по пикселям)
- Фон/полосы: **#000000** (чистый чёрный)
- Карточки: **#ffffff / #f5f5f5**
- Акцент: **#8043CE** (пурпур) — прогресс-бар, верхняя кромка панели, маркеры
- Прогресс-заливка: градиент #8B75A6 -> #8043CE -> #9858E4 (лёгкое свечение)

## Структура (главный экран)
- **Левый сайдбар**: узкий чёрный (в превью ~3% ширины)
- **Главная зона**: светлая #f5f5f5 с **пурпурной верхней кромкой** (2px accent line)
- **Hero-карточка** (белая, слева в основной зоне): заголовок + подзаголовок вверху,
  список из 4 строк в середине (треки/очередь)
- **Горизонтальный плеер**: [светлая карточка-арта] [вертикальный пурпурный прогресс-столбик]
  [белая карточка информации о треке]
- **Обложка**: реальное фото (тёплые тона) в правом нижнем углу
- Внизу: тонкая серая полоса-бейдж под карточкой

## Ключевые выводы для Авроры
1. Чёрный фон + БЕЛЫЕ карточки (инверсия текущего тёмного — «тёмная база #0F-14»
   уходит; фон #000, карточки почти белые)
2. Один акцент #8043CE вместо лаванды #8F84C9
3. Пурпурная кромка сверху панелей (accent top-border)
4. Прогресс — заметный вертикальный/горизонтальный элемент с градиентом
5. Сайдбар остаётся, но чёрный и ужимается


## Детальная структура главного фрейма (player, node 22-54)
Горизонтальная композиция из трёх блоков:
```
[ АРТ-КАРТОЧКА ] [ ПУРПУРНЫЙ ПРОГРЕСС-БАР ] [ БЕЛАЯ ПАНЕЛЬ ИНФО ]
   x .12-.26        x .26-.35 (вертикальный)   x .36-.88
   высокая (~70%      полная высота арта,        y .13-.89:
   высоты фрейма)     #8043CE с градиентом       заголовок (y .17),
                                                    подзаголовок (y .21),
                                                    ряд мета/кнопок (y .34)
[ мал. светлая полоса-кнопок под артом x .13-.28 ]
```
- Прогресс-бар — **вертикальный столбик во всю высоту карточки арта**,
  сразу правее неё (ширина ~3% фрейма)
- Арт — портретная карточка (выше, чем шире)
- Инфо-панель доминирует (больше половины ширины), текстовые строки
  сверху, ниже — сплошная белая заливка
